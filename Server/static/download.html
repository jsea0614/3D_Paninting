색칠 앱 받기

이 PC의 번호를 누르면 번호와 서버 주소가 미리 설정된 색칠 앱(zip)을 받습니다.

빌드 확인 중…

지금 이 주소(localhost)로 받으면 학생 PC에서 서버를 찾지 못합니다. 학생 PC에서 서버 IP 주소(예: http://192.168.0.10:8081/download)로 여세요.

  1. 브라우저가 "안전하지 않은 다운로드"라고 막으면 유지(또는 계속)를 누릅니다.
  2. 받은 zip을 오른쪽 클릭 → 압축 풀기. 바탕 화면 같은 곳에 풉니다 (zip 안에서 바로 실행하면 안 됩니다).
  3. PaintApp\PaintApp.exe를 실행합니다. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행.
  4. 방화벽 창이 뜨면 허용. 왼쪽 위 학생 번호, 오른쪽 위 초록색 '연결됨'이 보이면 준비 완료입니다.
